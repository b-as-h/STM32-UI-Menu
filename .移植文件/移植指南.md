# STM32 OLED 菜单系统移植指南

## 文件说明

### 必须移植的文件
| 文件 | 说明 |
|------|------|
| `oled.h/c` | SSD1306 OLED 驱动（I2C接口，128x64分辨率）|
| `font.h/c` | 字体库（ASCII + 中文）|
| `key.h/c` | 按键检测（状态机消抖）|
| `simple_menu.h/c` | 菜单系统 |

### 文件夹结构
```
your_project/
├── Core/
│   ├── Inc/
│   │   ├── oled.h
│   │   ├── font.h
│   │   ├── key.h
│   │   └── simple_menu.h
│   └── Src/
│       ├── oled.c
│       ├── font.c
│       ├── key.c
│       └── simple_menu.c
```

## 移植步骤

### 第1步：复制文件
将 `.移植文件` 文件夹中的所有 `.h` 和 `.c` 文件复制到你的项目对应目录：
- `Inc/` → 你的项目 `Core/Inc/`
- `Src/` → 你的项目 `Core/Src/`

### 第2步：CubeMX 配置
1. **I2C 配置**
   - 启用 I2C（通常 I2C1）
   - 配置速度：400kHz（Fast Mode）
   - SCL/SDA 引脚根据你的硬件接线配置

2. **按键 GPIO 配置**
   - 配置按键引脚为 `GPIO_Input`
   - 上拉/下拉根据硬件决定（通常上拉，按下接地）

3. **重新生成代码**
   - 点击 `Generate Code`
   - **注意**：不要覆盖你手动添加的代码

### 第3步：修改引脚定义
打开 `Core/Inc/main.h`，确认引脚定义：
```c
// OLED 引脚（I2C 自动配置，无需手动定义）
// 按键引脚 - 根据你的硬件修改
#define key_up_Pin        GPIO_PIN_xx
#define key_up_GPIO_Port  GPIOx
#define key_down_Pin      GPIO_PIN_xx
#define key_down_GPIO_Port GPIOx

// LED 引脚（可选）
#define led_up_Pin        GPIO_PIN_xx
#define led_up_GPIO_Port  GPIOx
#define led_down_Pin      GPIO_PIN_xx
#define led_down_GPIO_Port GPIOx
```

### 第4步：修改 I2C 句柄
打开 `oled.c`，确认 I2C 句柄名称：
```c
void OLED_Send(uint8_t *data, uint8_t len)
{
  // 确保 hi2c1 与你的 CubeMX 配置一致
  HAL_I2C_Master_Transmit(&hi2c1, OLED_ADDRESS, data, len, HAL_MAX_DELAY);
}
```

### 第5步：修改按键引脚
打开 `key.c`，确认按键引脚：
```c
uint8_t key_process(void)
{
  // 确保引脚名称与 main.h 中的定义一致
  uint8_t pin_up = HAL_GPIO_ReadPin(key_up_GPIO_Port, key_up_Pin);
  uint8_t pin_down = HAL_GPIO_ReadPin(key_down_GPIO_Port, key_down_Pin);
  // ...
}
```

### 第6步：添加到编译
在 Keil 中：
- 点击 `Project` → `Manage Project Items`
- 确保所有 `.c` 文件都添加到项目中

在 STM32CubeIDE 中：
- 右键点击 `Core/Src` → `Properties`
- 确认文件夹被包含在编译路径中

## 使用方法

### 1. 基本初始化
```c
#include "oled.h"
#include "key.h"
#include "simple_menu.h"

int main(void)
{
  // ... HAL_Init(), SystemClock_Config(), MX_GPIO_Init(), MX_I2C1_Init() ...

  // 初始化 OLED
  OLED_Init();
  HAL_Delay(20);  // 等待 OLED 稳定

  // 初始化菜单系统
  Menu_Init();

  // 创建菜单结构
  Menu_CreateMenu(0, "Main Menu", 0);        // 根菜单 (ID: 0, 无父菜单)
  Menu_AddItem(0, 1, "Settings");            // 向根菜单添加菜单项
  Menu_AddItem(0, 2, "Sensors");
  Menu_AddItem(0, 3, "About");

  Menu_CreateMenu(1, "Settings", 0);         // 子菜单 (ID: 1, 父菜单ID: 0)
  Menu_AddItem(1, 11, "Brightness");
  Menu_AddItem(1, 12, "Volume");

  // 显示初始菜单
  Menu_Show();

  while (1)
  {
    uint8_t key_event = key_process();

    if (key_event == KEY_UP_PRESSED)
    {
      Menu_KeyUp();      // 选中项上移
      Menu_Show();       // 刷新显示
    }
    else if (key_event == KEY_DOWN_PRESSED)
    {
      Menu_KeyDown();    // 选中项下移
      Menu_Show();       // 刷新显示
    }

    HAL_Delay(10);  // 降低 CPU 占用
  }
}
```

### 2. API 说明

#### OLED 函数
```c
OLED_Init();                           // 初始化屏幕
OLED_NewFrame();                       // 开始新一帧
OLED_ShowFrame();                      // 刷新到屏幕

// 绘图
OLED_DrawLine(x1, y1, x2, y2, color);
OLED_DrawRectangle(x, y, w, h, color);
OLED_DrawFilledRectangle(x, y, w, h, color);
OLED_DrawCircle(x, y, r, color);
OLED_DrawFilledCircle(x, y, r, color);

// 文字
OLED_PrintASCIIString(x, y, str, &afont12x6, color);
OLED_PrintString(x, y, str, &font16x16, color);  // 支持中文
```

#### 菜单函数
```c
Menu_Init();                           // 初始化菜单系统
Menu_CreateMenu(id, title, parent_id); // 创建菜单
Menu_AddItem(menu_id, item_id, name);  // 添加菜单项
Menu_Show();                           // 显示当前菜单

Menu_KeyUp();                          // 上移选中项
Menu_KeyDown();                        // 下移选中项
Menu_KeyConfirm();                     // 确认/进入子菜单
Menu_KeyBack();                        // 返回上级菜单
```

#### 按键函数
```c
key_process();                         // 检测按键事件
key_up_is_pressed();                   // 查询上键是否按下
key_down_is_pressed();                 // 查询下键是否按下
```

## 常见问题

### Q1: OLED 不显示
- 检查 I2C 地址是否正确（默认 0x78）
- 检查硬件接线（SDA/SCL）
- 确认 I2C 已初始化

### Q2: 按键无响应
- 检查 GPIO 配置为 Input 模式
- 确认上拉/下拉配置正确
- 检查 `main.h` 中的引脚定义

### Q3: 编译报错 "undefined reference"
- 确保所有 `.c` 文件都已添加到项目
- 检查 CubeMX 是否覆盖了手动代码

### Q4: 中文显示乱码
- 编译器设置字符集为 UTF-8
- 使用波特律动取模工具生成中文字库
